# Querida Lara Jean 🌹

Una carta romántica digital hecha con HTML, CSS y JavaScript puro.

## 1. Abrir el proyecto
1. Descarga y descomprime `querida-lara-jean.zip`.
2. Abre la carpeta `querida-lara-jean`.
3. Haz doble clic en `index.html` para probarlo en tu navegador.
4. Para editar el código, abre la carpeta con Visual Studio Code.

## 2. Agregar tu música (paso necesario)
Por derechos de autor, el proyecto no incluye una copia de la canción “Querida Lara Jean”.
Debes conseguir por tu cuenta un archivo MP3 que tengas derecho a usar.

1. Coloca el archivo dentro de la carpeta `audio`.
2. Cámbiale el nombre exactamente a `querida-lara-jean.mp3`.
3. Si tu archivo tiene otro nombre, cambia también el valor `src` en `index.html`.
4. Vuelve a abrir la página y pulsa “Abrir mi carta” o el botón ♫.

La reproducción automática puede estar bloqueada hasta que la persona toque un botón. Eso es normal en los navegadores.

## 3. Personalizar la carta
Abre `index.html` y busca la sección `letter-copy`.
Edita los párrafos para escribir tu propio mensaje. También puedes cambiar la firma “Alguien que te quiere”.

Para cambiar el nombre del título, busca `Querida Lara Jean` en `index.html`.

## 4. Publicar gratis con GitHub Pages
1. Inicia sesión en GitHub y crea un repositorio nuevo, por ejemplo `querida-lara-jean`.
2. Descomprime el ZIP y entra en la carpeta del proyecto.
3. Sube al repositorio todos los archivos y carpetas que están dentro de `querida-lara-jean` (no subas el ZIP).
4. En GitHub, abre **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**.
6. Selecciona la rama `main` y la carpeta `/ (root)`, luego pulsa **Save**.
7. Espera a que GitHub Pages publique la página. La dirección aparecerá en la sección Pages.

## 5. Importante sobre el audio y la privacidad
- GitHub Pages publica el contenido del repositorio. Si subes el MP3, cualquiera que visite la página podría acceder a ese archivo.
- No subas música protegida por derechos de autor sin autorización. Si no tienes permiso para publicarla, deja el audio fuera y usa una pista propia o con licencia adecuada.
- Los nombres de archivos distinguen mayúsculas y minúsculas al publicarlos. Mantén las rutas exactamente como aparecen.

## Archivos
- `index.html`: estructura y texto de la carta.
- `css/styles.css`: diseño, colores y animaciones.
- `js/script.js`: interacción, música y pétalos.
- `assets/roses/rose.svg`: ilustración vectorial de rosas.
- `audio/`: coloca aquí tu MP3 autorizado.
